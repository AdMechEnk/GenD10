# GenD10
Foundry VTT system development playground for GenD10 system

## Overview
This is a Foundry VTT system for the GenD10 game system, providing the core functionality needed to run games using this system.

## Features
- Core game mechanics implementation
- Character sheet and token management
- Roll system integration
- Custom actor and item types

## Installation
1. Download the latest release from the [releases page](https://github.com/AdMechEnk/GenD10/releases)
2. In Foundry VTT, go to Game Systems and click "Install System"
3. Select the downloaded zip file

## Development
To set up the development environment:
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run build` to compile the system
